Rope rescue planner

Build a rescue plan for a rope access job. Pick the rigging setups that fit the job, and each one gets a drawing, a step-by-step method, a backup plan and an equipment list. Save it all as one PDF.

Draft plan. Setups and steps follow the IRATA ICOP (TC-102) and TACS (TC-101, issue 006) rescue requirements, written in plain words. Check each plan against the site risk assessment and the equipment makers' instructions. The Level 3 supervisor must approve it and brief the team before work starts.
